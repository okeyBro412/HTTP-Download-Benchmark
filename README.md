# HTTP Download Benchmark

Консольный скрипт на Python для замера скорости скачивания файла при последовательных HTTP-запросах.

## Требования
* Python 3.7 или выше.
* Сторонние библиотеки не требуются (используются только встроенные модули `urllib`, `time`, `sys`).

## Запуск

Выполните команду в терминале:
```bash
python benchmark.py
```
После запуска скрипт попросит ввести ссылку на файл в консоли и нажать Enter.

## Единицы измерения

* **Время запроса:** секунды (`сек.`). Для замеров используется высокоточный таймер `time.perf_counter()`.
* **Объем скачанных данных:** двоичные мегабайты (`МБ`, где 1 МБ = $1024 \times 1024$ байт) и точное количество байт.
* **Скорость скачивания:** мегабиты в секунду (`Мбит/с`, где 1 Мбит = $1\,000\,000$ бит). Это общепринятый стандарт измерения пропускной способности интернет-канала.
